Does Java matter in the age of AI? What problem are we even trying to solve anymore? Are we still having fun? In this
talk Holly will explain why Java very much matters, and why it's a great choice for modern development. She'll survey
the current technology landscape to show how Java is delivering wins in sustainability, maintainability, and longevity.
These translate into resource efficiency, time efficiency, and token efficiency. There will be numbers. There will be
demos. There will be TUIs, and tools. There will be pictures, and possibly even explosions.
